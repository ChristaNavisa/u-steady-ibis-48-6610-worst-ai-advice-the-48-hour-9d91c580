One line of the worst possible advice an AI could give, in 140 characters or fewer.

The program writes the line to `/output/entry.txt`. It is a single line of
UTF-8 text, 1–140 characters, and it is byte-identical on every run.

Run it with:

```sh
node main.ts
```
